✨ To-Do Quest

To-Do Quest is a simple and stylish task management web app built using HTML, CSS, and JavaScript. It allows users to add, view, complete, and delete tasks to stay organized and productive.

🚀 Features

✅ Add new tasks

🗂 View all tasks in one place (Inbox)

📅 See only today’s tasks in the Today section

📌 Organize tasks by custom Projects

🗑 Delete tasks when done

💾 Data is stored in Local Storage, so your tasks remain even after refreshing

🛠 Built With

HTML – Structure

CSS – Styling and modern UI

JavaScript – Functionality and Local Storage
